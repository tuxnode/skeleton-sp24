Lab 01: Setup - 配置 IntelliJ, Git, Java 17 环境。

Lab 02: Debugging - 学习使用 IntelliJ 调试器，寻找 IntList 里的 Bug。

Lab 03: Randomized Testing - 学习编写随机测试（对比实验），验证代码正确性。

Lab 04: Git - 深入理解 Git 原理，处理 Merge 冲突。

Lab 05: UnionFind - 实现并查集（Weighted Quick Union + 路径压缩）。

Lab 06: BSTMap - 使用二叉搜索树（BST）实现 Map 接口。

Lab 07: LLRB - 实现左倾红黑树（一种平衡二叉搜索树）。

Lab 08: HashMaps - 手写哈希表（处理冲突、负载因子、扩容）。

Lab 09: P3 Prep - Project 3 的预演，学习如何处理键盘输入和 Tile 渲染。

Lab 10: Tries - 实现前缀树（Trie），用于高效字符串搜索。

(后续 Lab 涉及图论算法如 Dijkstra 和 MST)

2048 Project 0 实现 2048 游戏的核心逻辑（移动、合并、胜负判断）。 Java 基础语法、循环、二维数组。

Deques Project 1A/1B 手写双端队列（Deque），分别用链表和循环数组实现。 链表、数组扩容、泛型、接口、单元测试。

Ngordnet Project 2 开发一个字频分析器（类似 Google Ngram），处理 WordNet 语义网数据。 图（Graphs）、哈希表、最小优先级队列、大型数据处理。

BYOW Project 3 Build Your Own World。随机生成一个可探索的 2D 瓦片地图世界。 随机算法、软件架构设计、持久化存储、UI交互。

HW 0A & 0B: Java 语法热身（循环、数组、对象）。

HW 1: 社交作业（了解课程规范，通常不需要写代码）。

HW 2: Asymptotics & Disjoint Sets: 理论分析。计算代码的时间复杂度（Big-O），以及并查集的选择题。

HW 3 & 4: 考试复习卷（Conceptual Homework）。这些作业通常在期中和期末前发布，涵盖了排序、图论、哈希等所有学过的概念，需要在 Gradescope 上完成。
